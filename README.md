ros_serial2wifi 是一个基于 ROS 2 的串口转 WiFi 驱动程序，由鱼香 ROS（fishros）社区开发。它的核心作用是让只有串口（UART）的硬件设备，通过 WiFi 网络接入 ROS 2 系统，实现数据的无线透传。

核心功能与工作原理
这个库本质上是一个串口与 TCP/IP 网络之间的协议转换器。

功能定位：它旨在将传统的串口设备（如激光雷达、IMU、单片机等）接入无线局域网，从而摆脱物理线缆的束缚，实现远程控制和数据采集。

工作原理：程序内部会启动一个 TCP 服务器（tcp_server） 节点，监听网络端口。当有 WiFi 客户端连接时，它会将接收到的网络数据转发到指定的物理串口，同时将串口收到的数据通过网络发送回去，实现双向透明传输
